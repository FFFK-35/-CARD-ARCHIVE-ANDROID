# CARD ARCHIVE — Android Widget

Native Android home-screen widget for CARD ARCHIVE.

## Project goals

- Kotlin + Android App Widget (RemoteViews)
- Compact 2×2 home-screen layout
- One tap to check in
- Local persistent data; no account or cloud sync required
- Preserve the existing CARD ARCHIVE HTML prototype data through an explicit import/migration flow

## Check-in rules

- At most one check-in per local calendar day
- +20 coins per valid check-in
- +30 bonus coins at each 3-check-in milestone
- One standard chest at each 6-check-in milestone
- Rest days never reset progress or remove rewards
